DECISIÓN TÉCNICA SICC-2026-003

Adopción de Norma Unificada CENELEC Seguridad de Software bajo FRA 49 CFR §236.1015 (PTCSP)

Ref: Modernización del Dossier de Seguridad Asunto: Blindaje Software Onboard/Wayside Estatus: VINCULANTE - SICC v6.4.21
I

Justificación Técnica

La norma legacy Seguridad de Software bajo FRA 49 CFR §236.1015 (PTCSP) se restringe únicamente al software de vía. En un sistema PTC Virtual (Virtual Fixed Block §236.1005), el 90% de la lógica reside en el tren. Mantener la 50128 genera un vacío de certificación que obliga injustificadamente a instalar hardware físico lateral.

La Seguridad de Software bajo FRA 49 CFR §236.1015 (PTCSP):2023 unifica los requisitos para software de vía y embarcado, garantizando una certificación integral sin parches de infraestructura.

II

Decisión Soberana

DICTAMEN NORMATIVO

1. Se adopta la Seguridad de Software bajo FRA 49 CFR §236.1015 (PTCSP) como estándar único para todo el software de seguridad del proyecto.
2. Se invalida la aplicación de la Seguridad de Software bajo FRA 49 CFR §236.1015 (PTCSP) por ser incompatible con el diseno PTC Onboard aprobado.
