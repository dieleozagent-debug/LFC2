# DECISIÓN TÉCNICA: DT-ENCE-002-2025-10-07
## ASUNTO: AJUSTE PRESUPUESTAL Y DEFINICIÓN DE ALCANCE - INTERFACES CTC-ENCE

**ESTADO:** PENDIENTE DE VALIDACIÓN HUMANA
**FECHA DE SANEAMIENTO:** 13 de abril de 2026

---

### 🏛️ 1. JUSTIFICACIÓN TÉCNICA
Se formaliza el ajuste del valor unitario del ítem **WBS 1.3.106** (Interfaces CTC-ENCE) para reflejar los costos reales de integración de sistemas de seguridad vital. El valor original de $60M COP se encontraba subestimado, no cubriendo los requerimientos de ciberseguridad ferroviaria y certificación de protocolos SIL-4 necesarios para la comunicación redundante entre el Centro de Control de Tráfico (CTC) y los Enclavamientos Electrónicos (ENCE).

### ⚙️ 2. DEFINICIÓN DE ALCANCE (LAS 5 INTERFACES)
Conforme al **Apéndice Técnico 1 (AT1)** y la **WBS 1.3.100-104**, se establecen las 5 ubicaciones mandatorias para estas interfaces, cada una operando como un nodo distribuido y autónomo:

| # | Ubicación (Nodo ENCE) | Función de la Interface |
|:--|:----------|:----------------------------|
| **1** | **La Dorada (CCO)** | Interfaz de Enclavamiento Local con sistema central CTC |
| **2** | **Puerto Berrío** | Integración de lógica de estación y apartaderos |
| **3** | **Barrancabermeja (Puerto)** | Gestión de interfaz de seguridad para cruce industrial |
| **4** | **García Cadena** | Nodo de seguridad regional y monitoreo de tráfico |
| **5** | **Zapatosa** | Interfaz de enclavamiento para gestión de surcos y capacidad |

### 💰 3. AJUSTE PRESUPUESTAL
- **Valor Unitario Propuesto:** $120.000.000 COP
- **Justificación:** Incluye Hardware de comunicaciones industrial, redundancia de canal (Fibra/Radio), capas de encriptación certificada y proceso de validación e integración en sitio. Este valor se alinea con el benchmarking de mercado para sistemas de senalización PTC de última generación.
